# 📘 Proyecto: Control de Asistencia en C#

## 📌 Descripción
Este programa permite al usuario **gestionar la asistencia de estudiantes** mediante un formulario en **Windows Forms**.  
El sistema utiliza un **ListBox** para mostrar la lista de estudiantes, un **CheckBox** para marcar si están presentes y un **Button** que genera un resumen de los asistentes registrados.

---

## 🚀 Funcionalidades
- Registro de estudiantes en un **ListBox**.
- Opción de marcar asistencia con un **CheckBox** (“Presente”).
- Generación de un resumen de los estudiantes presentes mediante un **Button**.
- Visualización dinámica de la lista de asistencia.

---

## 🛠️ Tecnologías utilizadas
- Lenguaje: **C#**
- Entorno: **Aplicación de Windows Forms**

---

## 📂 Estructura del código
El programa se organiza de la siguiente manera:

- **Espacio de Nombre:** `Control_Asistencia`  
- **Clase principal:** `Form1`  
- **Eventos principales:**  
  - `btn_Registrar_Click`: Agrega estudiantes al **ListBox**.  
  - `chk_Presente_CheckedChanged`: Marca si el estudiante está presente.  
  - `btn_Resumen_Click`: Genera un resumen de los asistentes.
